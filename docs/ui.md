## 大事にすること

1. **片手で「続き」か「未再生」をすぐ流せること。** 主な聴取シーンは寝る前・移動中で、腰を据えて番組を選ぶ時間は短い。操作は画面の下半分（親指が届く範囲）に寄せる
2. **学習コストを増やさないこと。** 番組 → 各回 → 再生 の 3 階層と、各画面の役割は固定する。動線は「入口を減らす」方向にだけ動かす
3. **個性は構造ではなく色で出すこと。** dynamic color は使わず、固定パレットで「ラジオらしさ」を持たせる。構造を動かさずに済むので実装コストが色・タイポの定義に閉じる
4. **手元／サーバの別、固定、消失は隠さないこと。** オフライン優先とフォルダ同期が差別化点なので、その状態は一覧の行に出す

## 色

固定パレット。ダークが主（寝る前の利用）で、ライトも同じ構成。既定は端末の設定に追従し、設定の「テーマ」で システム／ダーク／ライト を選べる（「端末はライトのままアプリだけ常にダーク」にできるように）。

温かい黒（赤みのある黒）にアンバーのアクセント。状態を表す色は **`primary`（アンバー）と `error`（赤）の 2 系統だけ** にし、それ以外の意味を色に持たせない（聴いている回の行の背景だけ `secondaryContainer` で示す。タブの選択の表示は下の「共通の規則」）。

## タイポグラフィ

- 書体はシステムのまま（Material3 の既定 `Typography`）
- **数字は等幅（`tnum`）。** `未再生 3`・`1:23:45`・`12.3 GB` のように数が並ぶ場面が多いので、桁が揺れないようにする。全スタイルに付ける

## 画面ごとの役割

### 番組の画面（根）

**役割**: 聴く回・番組を選ぶ根の画面。タイトルは「Kikidame」。

- トップバーのすぐ下に「続きから・よく聴く・番組一覧」のタブ（`PrimaryTabRow`、左右のスワイプでも切り替わる）。下はミニプレイヤーで、ナビゲーションバーは置かない（置くと下部がミニプレイヤーとナビゲーションバーの 2 段になって厚くなるため）。起動時は前回最後に開いていたタブ（初回は「続きから」）
- 「続きから」は途中まで聴いた回を番組をまたいで最後に聴いた順に並べる。行は `タイトル` / `番組名 · 残り N 分` / 再生位置のバー。タップ・右端の再生済み・長押しのシートは各回一覧と同じで、ここで再生済みにしたときだけ［元に戻す］を出す
- 「よく聴く」は ★ の番組だけ、「番組一覧」は全番組を 1 本に（節に分けず、よく聴く番組は ★ で見分ける）。どちらも最新の各回の公開日が新しい順（同着は番組名の順）。空の「続きから」「よく聴く」には案内を出す
- 番組の行は `配信元 · 未再生 N / 手元 L · 全 E 回 · 最新 MM-DD`。同期対象の番組には同期対象の印を出す
- ★ の右、番組名の左に 48dp の正方形で番組の画像（ADR 0009）。画像の無い番組も 48dp を空けて（何も描かない）番組名の位置を全行でそろえる。ただし表示している一覧（「よく聴く」「番組一覧」のそれぞれ、絞り込みの後）に画像を持つ番組が 1 つも無ければ空けずに詰める。行の高さ（上下 8dp・最小 72dp）は画像の有無で変わらない
- 消失した番組の行には「取得元に見つかりません」と `CloudOff` アイコンを出す。並び順は消失で変わらない

**絞り込み**: 入口は 1 つ。検索と配信元は 1 枚のシートに入れ、選択中は検索語と配信元をそれぞれチップで出す。絞り込みは「よく聴く」「番組一覧」に効き、タブをまたいで保つ。「続きから」では絞り込みのボタンとチップを出さない。

### 各回一覧

**役割**: 番組の回を選ぶ・ダウンロード／固定／再生済みを操作する。

- トップバーのタイトル（番組名と配信元の 2 行）の左、戻るボタンの右に 40dp の正方形で番組の画像（ADR 0009）。画像の無い番組では何も置かない（場所も取らない）。各回の行には出さない
- 各回の行の補足行は `公開日 · 出演者 · 尺 · 状態`（タイトルが公開日と同じ回は公開日を省く。長い名前は折り返す）。固定・再生中の小アイコンはタイトルの前に置き、印の無い行にも同じ幅の枠を確保して開始位置を揃える（補足行へ移すと情報が増えて読みにくい）。タイトルは 1 行
- 手元に無い各回は同じ並びで薄く表示し、タップしても再生画面へ行かない

**行の操作**:

- 右端のアイコンは状態表示と、最も自然な 1 操作。雲 → ダウンロード（= 固定）、進捗リング → キャンセル、警告 → 再試行、手元にある回は再生済み切替
- 長押しのシートに、固定する／固定を外す／ファイルを削除／再生済み切替／ダウンロード／詳細を出す
- 「固定する（保持ルールの対象外にする）」は、手元にあり（`DONE`）固定していない回に出す（同期で落とした回を、ファイルを落とし直さずに固定する。番組が同期対象かは見ない。「続きから」のシートにも同じ条件で出す）。「固定を外す」は同期対象の番組の固定中の回だけに出す（同期対象でない番組で外すと次の同期で消えるため）
- 同期対象の番組で保持すべき回のファイルを削除したときは、「同期対象の番組なので次の同期で落とし直されます」と知らせる。聴かない回は再生済みにするのが正規の操作で、「除外」の状態は無い
- 手元のファイルが無くなっていたときは「ファイルが見つかりません」と知らせる

**引っ張って更新**: 1 番組の同期（取り込み → この番組だけの同期）。固定していない手元のファイルは保持ルールに従って消え、同期対象の番組なら予約もする。同期を OFF にした番組でも同じで、確認は出さない。番組の行が無い・取得元 ID が無い番組は全体の同期に切り替わる。画面を離れても最後まで続く（番組一覧の引っ張って更新も同じ）。

**同期のシート**（トップバーの同期のボタン）:

- 「この番組を同期する」のスイッチ、「最新 N 回まで保持」（選択式 1 / 3 / 5 / 10 / 20 / 上限なし）、「再生済みなら削除」のスイッチ。後の 2 つは同期 OFF でグレーアウト
- 同期していない番組のアイコンは `SyncDisabled`（斜線入り）で、形で区別する
- ON に切り替えるたび、「最新 N 回」が未設定なら 3 を入れる
- スイッチやチップを触っている間は保存するだけで同期しない。シートを閉じたとき（閉じる経路は問わない）に、開いたときから設定が変わっていれば、その番組の 1 番組の同期が走る（ダウンロードも削除も。元の値に戻して閉じたときは走らない）。走っている同期があれば終わるのを待ってから走る。走っている間はクルクルを出し、結果の文言は引っ張って更新と同じ
- OFF に切り替えるとき、手元に固定されていない回が N 本あれば「固定されていない N 回のファイルが、このシートを閉じると削除されます。残したい回は先に固定してください」の確認のダイアログを出す
- 取得元 ID の無い番組はスイッチを無効にし、「取得元に見つかっていないため同期できません」と出す
- 消失した番組ではスイッチを無効にして消失を知らせ、手元の回はそのまま聴ける。その下の **「この番組を手元から消す」**（確認 → 番組・各回・ファイル・再生位置をすべて消す）は、消失した番組と取得元 ID の無い番組だけに出す（取得元に在る番組を消しても次の同期で戻り、再生位置だけ失うため）

### 再生画面

**役割**: 聴いている回の操作。左右スワイプでシーク。

- タイトルの下に `配信元 · 出演者`（無い回も 1 行分の場所は確保する）
- 倍速・再生済み・スリープをシークバー下の中央 3 列に置く。再生済みは TopAppBar に置かない
- **画像**: タイトルの上の正方形の枠に番組の画像（ADR 0009）。切り抜かず全体を出す（`ContentScale.Fit`。横長・縦長の画像は枠の中に収まり、余りは画面の背景のまま。番組一覧・各回一覧・ミニプレイヤーは正方形に切り抜く `Crop`）。枠は幅の 6 割を上限に、ボタン類が画面に収まらなければその分だけ縮める。画像の無い番組では何も置かない（場所も取らない）。画像もスワイプのシークを拾う範囲に入る
  - 中身は回の画像（各回のファイルに埋め込まれた画像。再生に入った回の分をサービスが手元のファイルから読む）を優先し、無ければ番組の画像。どちらも無ければ何も置かない。通知・ロック画面・Android Auto の再生中の表示も同じ順の画像（縮めたバイト列を `artworkData` で渡す）
  - 回の画像が載るのは再生に入った後なので、一瞬番組の画像が先に出てから替わることがある。回に載った後は、同期が番組の画像を取り直しても、次に回が替わるまで再生画面・通知の画像は差し替わらない
- **チャプター**（各回のファイルに埋め込まれたもの。`CONTEXT.md`）は再生画面だけに出し、通知・ロック画面・Android Auto には出さない
  - スワイプ中だけ「差分 → 目標の位置」を出している行（場所は常に確保）に、普段は今のチャプターの題を `onSurfaceVariant` で 1 行で出す。1 行に収まらないときだけ `Modifier.basicMarquee()` で横に流す（収まるときは止まったまま。回数は限らず繰り返し、端まで流れたら 2.5 秒止まって頭からまた流す。`basicMarquee(iterations = Int.MAX_VALUE, repeatDelayMillis = 2_500)`）。スワイプ中は差分の表示（primary）に替わって流さず、離すと題に戻って流れ直す。チャプターの無い回、または最初のチャプターの開始より前は空白
  - シークバーの下の倍速・再生済み・スリープの列に、チャプターのある回でだけ 4 つ目の「チャプター」（英語は「Chapters」。一覧のアイコン）を足す（無い回は 3 列）。押すとボトムシート（倍速・スリープと同じ開き方）で、各行は開始の時刻（`toClockText` の形）と題。今のチャプターの行は面の色（`secondaryContainer`）を変えて再生中の印（▶）を付け、開いたときにその行までスクロールする。行を選ぶとその開始へシークしてシートを閉じる（再生中か一時停止中かはそのまま）。`isHidden` のチャプターは出さない
  - 最初のチャプターはいつも 0:00 から始まって見える（本当の開始は media3 が捨てる `chpl` にしか無いため）。前後のチャプターへの送りのボタンと、シークバー上の区切りの印は出さない
  - 再生中の位置は秒の境目（とチャプターの開始）の直後に読み、秒が均等に進むようにしている

### ミニプレイヤー

**役割**: 一覧の下で「聴いている回」を示し、再生画面へ戻る入口。

- 上端に再生位置の線、面をアンバー系にする
- 行の左に 40dp の正方形で、聴いている回の番組の画像（ADR 0009）。画像の無い番組では何も置かない（場所も取らない）。回の画像は使わない

### 設定

**役割**: 取得元・ダウンロード・表示（テーマ）の設定と、アカウント（ログアウト・取得元を変える）。

- 表示専用の行は「ラベル上（overline）・値下（headline）」に揃える（詳細画面と同じ向き）
- **「取得元」の節**: 今の取得元の種類（Jellyfin / NAS の共有フォルダ（SMB）/ 端末のフォルダ）を出す。Jellyfin なら URL・ユーザー・ライブラリ（タップで選び直す）、SMB ならホスト・共有名・フォルダ（空なら「共有の直下」）・ユーザー（ゲストなら「ゲスト」）、端末のフォルダならフォルダの行に端末の中のパス（「内部ストレージ / KikidameTest / Radio」。内部ストレージ以外のボリュームはボリュームの ID をそのまま出す。ツリーの文書 ID が想定の形でなければ、選んだフォルダ自身の名前。`DeviceFolder.displayPath`）を出す。「取得元を変える」は、手元のデータを全部消して取得元の選択へ戻る
- **「最終同期」の行**（値は最後に全走査が成功した時刻）: 全走査の最後の試みがそれより新しく成功でないときだけ、補足の行を 1 行足す。失敗は `error` の色で「2026-10-26 14:00 に失敗: <理由>」（理由は同期の失敗のスナックバーと同じ文言）、「Wi-Fi のみ」で従量制だったときの見送りは通常の色で「2026-10-26 14:00 は Wi-Fi ではないため見送り」
- **「再生の共有」の行**: 取得元が Jellyfin のブックのライブラリのときだけ、「最終同期」の下に出す（ADR 0010 の決定 8。ほかの取得元では行ごと出さない）。値は最後に共有できた時刻（「2026-10-26 14:00 に共有」。まだ無ければ「まだ共有していません」）で、最後に送れなかったのがそれより新しければ `error` の色で補足を 1 行足す（「2026-10-26 14:00 に送れませんでした: <理由>。送れなかった分は次の同期で送ります」。理由は同期の失敗と同じ文言）。通知は出さない
- **「ダウンロード」の節**:
  - 「手元のファイル」の行（合計 `1.23 GB（12 回）`）は、押すと手元のファイルの内訳の画面を開く（補足に「タップで内訳を見る」）
  - その行のすぐ下に、「取得元に見つからない番組を手元から消す（N 番組）」の行（対象は消失した番組と取得元 ID の無い番組。0 番組なら行ごと出さない）。押すと確認のダイアログ（「取得元に見つからない N 番組を手元から消します。手元の回 M 本（うち固定 K 本）と再生位置も消えます。取得元に戻っても、消したものは戻りません。」。固定が 0 本なら「（うち固定 K 本）」を省く。ボタンは赤の「消す」と「キャンセル」）を出し、固定した回や再生途中の回も区別せず、番組・各回・音声ファイル・再生位置・番組の画像を消す。聴いている回（プレイヤーに載っていて聴き終えていない回）の番組だけは消さずに残し、「聴いている番組 N 件は残しました」と知らせる（ダイアログの件数は残す分を除いたもの）。同期の間（操作による同期も裏の同期も）は行を無効にし、「同期の後に使えます」と出す
  - 「Wi-Fi のみ」の行の下に、このアプリが電池の最適化の対象のときだけ「電池の最適化を外す」の行を出す（補足は「外すと裏の同期が遅れにくくなります。電池の減りが少し増えることがあります」。対象外なら行ごと出さない。画面に戻るたび判定し直す。押すと OS の確認のダイアログを出す）

### 手元のファイルの内訳

**役割**: 設定の「手元のファイル」の行から開く。状態（固定・再生済み）で探して要らない回を消すことと、容量の大きい番組・回から減らすことのための画面。

- トップバーのタイトルは「手元のファイル」、その下に設定の行と同じ合計（`1.23 GB（12 回）`）、その下に「番組ごと」「すべての回」のタブ（`PrimaryTabRow`、左右のスワイプでも切り替わる）
- 手元の回は `DONE` でパスのある回だけ（ダウンロード中の回は出さない）で、容量は各回の `sizeBytes` の合計
- 「番組ごと」は手元の回のある番組だけを容量の大きい順に並べる。行は `番組名` / `N 回・XX MB／固定 a · ほか再生済み b · ほか未再生 c`（重ならない 3 つで、合計が N。固定は再生済みかを問わず固定に数え、「ほか」は固定でない回）。番組の行を押すと番組ごとの手元の回の一覧へ
- 「すべての回」は全番組の手元の回を容量の大きい順に 1 列に並べ、上に絞り込みのチップ「固定」「再生済み」（両方を選べば両方に当たる回だけ。見え方だけを変え、何も消さない。選んだ回が絞り込みで隠れると、ボタンの数・確認・消す対象からは外れる（選んだ印は残り、絞り込みを外すとまた数える））を置く
- 回の行は番組ごとの手元の回の一覧と同じで、補足の行の先頭に番組名を足す（`番組名 · 公開日 · 容量`）
- 消すボタンは「すべての回」のタブにいるときだけ出す。操作は「番組ごとの手元の回の一覧」と同じ

### 番組ごとの手元の回の一覧

**役割**: 内訳の画面の番組の行から開く。その番組の手元の回だけを選んで消す。各回一覧には移らない。

- トップバーのタイトルは番組名。その番組の手元の回だけを公開日の新しい順（各回一覧と同じ `EpisodeOrder.newestFirst`）に並べる
- 回の行は左にチェックボックス、タイトル（1 行。前に各回一覧と同じ固定の印）、補足の行 `公開日 · 容量` と、再生済みなら「再生済み」、取得元 ID の無い回（消すと戻せない回）なら「取得元に無い」の印。行を押すとチェックが付く・外れる（最初から選ぶ状態で、長押しで選ぶ状態に入る形は無い。詳細・再生には移らない）
- 聴いている回（プレイヤーに載っていて聴き終えていない回、`NowPlaying.excludedFromSync` と同じ定義）は各回一覧と同じ背景（`secondaryContainer`）にし、チェックボックスを無効にして選べなくする。「すべて選ぶ」は置かない
- 1 回以上選ぶと画面の下に赤の「N 回を消す（XX MB）」のボタン。押すと確認のダイアログ（「3 回（375 MB）のファイルを手元から消します。」に、取得元 ID の無い回があれば「うち 1 回は取得元に無いため、一覧からも消え、戻せません。」、同期対象の番組の回があれば「同期対象の番組の回は、保持すべき回なら次の同期で落とし直されます。」を足す。どの回が落とし直されるかの予測はしない。固定が外れることは書かない。ボタンは赤の「消す」と「キャンセル」）
- 消し方は各回一覧の 1 回ずつの削除と同じ規則で、消すときにも聴いている回を除き、除いたら「聴いている回 N 件は残しました」と続けて知らせる。消した後は行が消え、スナックバーで「N 回を消しました」。手元の回が 0 になったら内訳の画面に戻る
- 同期の間（操作による同期も裏の同期も）はボタンを無効にし、「同期の後に使えます」と出す（回を選ぶことはできる）

### 各回の詳細

**役割**: 回の情報と技術情報の行。

- 技術情報の「取得元 ID」の行は、Jellyfin では Jellyfin の id、共有フォルダでは共有フォルダの中の相対パス（`<配信元>/<番組>/<ファイル名>`）。取得元を種類で出し分けない

### 取得元の選択・接続・ライブラリ選択

**役割**: 初回と取得元を変えるときだけ通る。

- **取得元の選択**: 「Jellyfin に接続」「NAS の共有フォルダ（SMB）」「端末のフォルダ」のカード。Jellyfin のカードの説明は「Jellyfin サーバのブックか音楽のライブラリを使う」。Jellyfin か SMB のカードを押すと、ローカルネットワークの権限が要って無ければ要求してから接続画面へ進む（端末のフォルダでは要求しない）
- **SMB の接続**: ホスト・共有名・共有の中のフォルダ（省略可）・ゲストのスイッチ・ユーザー名・パスワード
- **接続画面の入口**: ログアウトした後は、直前に使っていた取得元の接続画面から始め（入力済み、パスワードは空）、一度も接続していなければ取得元の選択から。接続の画面は取得元の選択から来たときだけ戻るボタンを出す
- **「取得元を変える」**: ログアウトした後（戻るが無い）は、Jellyfin・SMB の接続画面と端末のフォルダの選択画面のどれにも置く（設定と同じ確認のダイアログと処理: 再生とダウンロード・同期の Worker を止め、手元をすべて消して取得元の選択へ。処理は `SourceChanger` で共有）。取得元の選択から来たときは戻るで選び直せるので置かない
- **端末のフォルダ**: カードを押すと説明の画面（`DeviceFolderScreen`）を開く。説明の画面には、3 段の構成の例（`Radio/<配信元>/<番組>/<回>.m4a`、等幅）、内部ストレージの直下や Download そのものは選べないこと、コピーしてから聴くこと、容量が二重になること（同期対象と保持ルールで絞れる）、フォルダのファイルを消すと手元のコピーも消えること（固定していても）を並べ、「フォルダを選ぶ」で OS のフォルダ選択を開く。端末のストレージ以外のフォルダを選ぶと、選び直しの案内を赤字で出す。
  端末のフォルダからログアウトした後（アクセスが切れたときを含む）は、この画面から始め、「フォルダ「内部ストレージ / KikidameTest / Radio」につながっていません。フォルダを選び直してください」のように端末の中のパスで案内を出し、「取得元を変える」も置く
- **Jellyfin のライブラリ選択**: 音楽に加えてブックのライブラリも選べる（行の補足は種類の「音楽」「本」）。それ以外のライブラリはグレーアウトし、一覧の上に 1 回だけ「音楽とブックのライブラリだけを選べます」。選べるライブラリが無ければ下に赤字で「音楽ライブラリもブックのライブラリもありません。Jellyfin 側でラジオ録音をブックのライブラリ（または音楽ライブラリ）として追加してから再読み込みしてください」。選べるライブラリが 1 つなら選択済みにして「決定」だけにする。設定の「ライブラリ」から選び直しても手元は消さず、「決定」の後の同期で結び直す（ADR 0010 の決定 7）

## 共通の規則

- 番組の行（`ProgramRow`）と各回の行（`EpisodeRow`。各回一覧と「続きから」で共通）は、左右のアイコン・ボタンを行が何行でも上下の真ん中に置き、3 行でも 1〜2 行と同じ上下 8dp・最小 72dp にする（Material 3 の `ListItem` は補足が折り返すと 3 行の項目になり、左右が上寄せで上下 12dp・最小 88dp になるため、`ListItem` は使わず `Row(verticalAlignment = CenterVertically)` で組む）
- 各回の行の再生位置のバーは、再生済みと未再生の間に隙間を空けない（`gapSize = 0.dp`。Material 3 1.4.0 の既定は隙間あり。隙間が無い点だけミニプレイヤーの線と同じで、色・端の形・端の点は既定のまま）
- 値を見せる行は `overlineContent` = ラベル、`headlineContent` = 値。操作の行は `headlineContent` = 操作名、`supportingContent` = 説明。少数の選択肢から 1 つ選ぶ行は `overlineContent` = ラベル、`headlineContent` = `FilterChip` の並び（保持ルールの「最新 N 回」、設定の「テーマ」）
- 状態の色は `primary`（よく聴く・同期対象・再生中）と `error`（消失・失敗・破壊的操作）だけ。聴いている回の行の背景は `secondaryContainer`。ただしタブは例外で、選んでいるタブの文字と下線に `primary`、選んでいないタブの文字に `onSurfaceVariant` を使う（`Tab` の既定は選んでいないタブも `primary` になる）
- 同期中の表示は 2 種類で、両方は出さない（ただし下のタグの件数の帯だけは例外）。利用者の操作（引っ張って更新、各回一覧の同期のシートを閉じたときの同期）はクルクル（`PullToRefreshBox`）、裏の同期（定期・起動時）は番組の画面（タブの下）・各回一覧のトップバーの下に細い不確定のバーと「バックグラウンドで同期中…」（`ui/BackgroundSyncBar.kt`）。裏の同期の最中に操作が来たらクルクルに切り替える。共有フォルダの全走査でタグを読んでいる間は、裏の同期でも操作による同期でも、番組の画面のタブの下に目盛りのあるバーと「タグを読み込み中 1,234 / 6,090」（読み終えた数 / タグを読む回の数）を出す。操作による同期では、クルクルとこの件数の帯を重ねて出す（「両方は出さない」の例外。件数は裏でも操作でも見せたいため）。タグを読む回が無い同期（2 回目以降で変化が無いとき）では出さない。各回一覧には出さない
- 同期の完了・失敗の伝え方。手動の同期の結果（変化・失敗・「Wi-Fi ではない」）はスナックバー（番組一覧・各回一覧を開いているときだけ）。裏の同期のスナックバーは変化があったときだけで、失敗は出さない。全走査の最後の試み（成功・失敗とその理由・「Wi-Fi ではない」の見送り）は手動でも裏でも記録し（1 番組の同期は記録しない）、設定の「最終同期」の行の補足に出す（最終同期より新しく、成功でないときだけ）。裏の同期の失敗が、最終同期から 24 時間以上続いたら Android の通知を 1 回出す（チャンネル「同期」、重要度は低。成功するまで出し直さず、全走査が成功すると手動でも裏でも消える。一度も成功していないとき・見送り・手動の失敗では出さない。押すと番組一覧を開く。通知が許可されていない端末では出さない）
- 同期の結果の文言は変化だけを出す: 「新しい回 N 件。Z 回をダウンロード予約、W 回を削除」（0 は省く）。判断保留の番組があれば「N 番組は取得元で見つからず、そのままにしました」を足す。手動の同期は変化が無ければ「最新の状態です」。従量制の接続で手動の同期をしたときは「Wi-Fi に接続していないため更新しません」。裏の同期は変化があったときだけ同じ文言を出す
- ボトムシートは「その画面に留まったまま 1 つ選ぶ」ときに使い、スクロールする長い一覧は画面にする
- データにある画像は出す。無いときは何も置かない（代わりの絵・頭文字の枠・偽の波形で埋めない）。出す画像は番組の画像（`CONTEXT.md`）と回の画像（`CONTEXT.md`。各回に埋め込まれた画像）。出す場所は、番組の画像が番組一覧の行・各回一覧のトップバー・ミニプレイヤー・再生画面で、回の画像が再生画面・通知・ロック画面・Auto の再生中の表示（回の画像を優先し、無ければ番組の画像。ADR 0009）

## 文言の足し方

UI の文言は英語と日本語の 2 言語で、OS の「アプリの言語」（Android 13+）で切り替わる。既定は英語（日英以外の端末には英語が出る）。解決の仕組み（`UiText`・例外）は [architecture.md](architecture.md) の「UI の文言（i18n）」、決定は ADR 0006。

- 文言は `app/src/main/res/values/strings.xml`（英語、既定）と `values-ja/strings.xml`（日本語）の**両方**に足す。片方だけだと lint の `MissingTranslation` でビルドが落ちる。`values/` には英語だけでは文脈が分からないキー（書式引数の意味、どの画面のどこか、`CONTEXT.md` の用語）に翻訳者向けの短いコメントを付け、書式引数は `%1$s` のように番号付きにし、数+単位（「3 回」「15 分」）は `<plurals>` にする
- キーは `<area>_<what>` の snake_case。area は `common` / `connect` / `source_pick` / `smb_connect` / `library_pick` / `program_list` / `episode_list` / `episode_details` / `player` / `settings` / `sync` / `playback` / `auto`。英語の用語は `CONTEXT.md` の英語名（Program / Episode / Publisher / Pinned / Starred / Played …）に揃える
- Composable では `stringResource` / `pluralStringResource` で解決する。Composable の外で文言を作るときは `UiText` を返す
- 日付（`2026-08-02`）・尺（`1:02:03`）・容量（`12.3 MB`）の書式は言語に依らず固定。言語で変わるのは区切り（`common_list_separator`「、」/ ", "）と単位だけ
- テスト: `UiText` を返す関数は `assertEquals(UiText.Plural(R.plurals.sync_new_episodes, 5), actual)` の形で「どの文言がどの引数で選ばれたか」を比べる。並びや省略を見たいテスト（行の補足など）は Robolectric に `@Config(qualifiers = "ja")` を付け、`resolve(context)` した日本語で比べる
- 3 言語目を足すときは `values-<lang>/strings.xml` を置くだけ（`generateLocaleConfig = true` が OS の言語一覧に自動で載せる）。翻訳の受け入れ体制（Weblate 等）は需要が見えてから

実機で見て方針と食い違ったら、この文書を直してから実装を変える。
